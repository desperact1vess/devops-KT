# K3-02. Первый workflow

Студент: Nikita.

`Student CI` находится в `.github/workflows/student-ci.yml`. Он настроен на события `push` и `pull_request`. Job `test` выполняется на `ubuntu-latest`: `checkout` получает исходники, `setup-python` подготавливает Python 3.13, `python --version` выводит версию. Job — отдельная задача на runner; steps — последовательные операции внутри задачи.

**Подтверждение ожидает запуска на GitHub.** Исходная версия workflow подготовлена в коммите `7e61488363ebddc6b99c7315d0cb8e5dda9728fc`. После запуска вписать ссылку на Student CI, фактические событие и SHA run, runner, шаги и строку `python --version`. Не считать локальную подготовку успешным запуском Actions.

Зелёный вывод версии Python подтверждает только доступность интерпретатора, но не поведение приложения: тесты в исходном шаблоне не запускаются.
